# Modo 26

Modo 26 es una aplicación web para presentar y gestionar el catálogo digital de una tienda de moda. Permite a los clientes explorar prendas por categorías, consultar precios, tallas y productos destacados, y enviar solicitudes de compra desde una experiencia visual adaptable a dispositivos móviles.

La solución también incorpora un panel administrativo para gestionar los productos publicados y centraliza la información mediante Supabase, facilitando la actualización del catálogo y reduciendo la dependencia de procesos manuales.
